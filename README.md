## 📝 整理原则

- **根目录 README**：所有游戏的总导航。
- **游戏目录 README**：该游戏下所有攻略的导航。
- **攻略文档**：保存稳定的路线、资料、收集点位等内容。
- **GitHub Issue**：用于记录个人动态进度，例如奖杯完成情况、收集数量和下次游玩目标。
- 默认优先使用 **简体中文版游戏内名称**；必要时在括号中保留英文名称，方便搜索外部资料。
