## 保险箱密码一览

左 / 右是操作方向，数字是目标刻度；按三段顺序输入后确认。点房间名可看具体路线。

| 保险箱 | 休闲 / 标准 | 癫狂 |
|---|---|---|
| [酒吧休闲室](./全流程解谜攻略.md#safe-bar) | **左10 → 右80 → 左30** | **右20 → 左50 → 右30** |
| [检查室](./全流程解谜攻略.md#safe-examination) | **右30 → 左10 → 右50** | **左50 → 右30 → 左90** |
| [疗养院地下](./全流程解谜攻略.md#safe-basement) | **右60 → 左40 → 右80** | **左70 → 右50 → 左20** |
| [方舟灭菌室](./全流程解谜攻略.md#safe-sterilization) | **右10 → 左90 → 右20** | **左80 → 右50 → 左0** |
| [方舟警备室](./全流程解谜攻略.md#safe-monitor) | **左50 → 右60 → 左80** | **右20 → 左0 → 右70** |

等候室已经打开的箱子不用密码；警局S.T.A.R.S.公文包密码是 **RRR**，不计入上述5个保险箱。密码来源和难度说明见[完整解谜章](./全流程解谜攻略.md#safes)。
