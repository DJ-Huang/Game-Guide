# 《Resident Evil Requiem / 生化危机9》白金攻略

> 适用场景：**已经首通一遍**，现在开始以最省时间、最稳妥的方式冲白金。
>
> 资料核对时间：2026-09-27。

## 白金概览

- 白金难度：约 **4/10**
- 总耗时：约 **20～30 小时**（首通已完成的话，剩余通常明显更短）
- 奖杯：**50 个**（1 白金 / 3 金 / 6 银 / 40 铜）
- 联机奖杯：**无**
- 推荐周目：**3 周目总计最稳**
- 最高难度：**Insanity（疯狂）**，首通后解锁
- 难度奖杯：**向下兼容叠杯**，疯狂通关会同时满足低难度通关奖杯
- 没有传统章节选择，因此手动存档非常重要
- 文件、浣熊纪念物等部分收集进度可跨周目累计
- 奖励菜单中的特殊物品可用于奖杯，不会导致奖杯失效

## 你现在最推荐的路线

你已经通关过一遍，因此不建议重新按“首周目全收集”的标准路线从头照抄。先打开游戏里的 **Challenges / 挑战** 菜单，看自己到底缺什么，然后按下面的顺序做。

### 阶段 0：先盘点首通成果

先不要急着开疯狂难度。

检查：

- 文件：75 个
- Mr. Raccoon Memoriam / 浣熊纪念物：25 个
- 保险箱：5 个
- BSAA 容器：3 个
- Plant 43 幼苗：9 个
- Bloodlust：累计收集 5000 infected blood microsamples
- 杂项战斗奖杯是否缺失
- 当前 CP 数量

**重要：先别把 CP 花在模型和概念艺术上。** 它们一共需要 10,000 CP，但属于最后收尾项目。现阶段 CP 应优先用来降低后续周目的难度。

---

## 阶段 1：补首通漏掉的收集与杂项杯

如果你首通时有保留各区域手动存档，优先直接读档补杯；没有的话就在下一次休闲速通时顺手补能够补的内容。

### 收集类

- **Case Closed**：阅读全部 75 份文件
- **You Little Rascal!**：破坏全部 25 个浣熊纪念物
- **No Safe is Safe**：打开全部 5 个保险箱
- **Crate Expectations**：打开全部 3 个 BSAA 容器
- **Not Today, Buds!**：消灭全部 9 个 Plant 43 幼苗

其中 **文件和浣熊纪念物可以跨周目累计**，所以如果首通已经拿了大部分，不必重新全部收一次。

### 比较容易漏的杂项杯

建议重点检查：

- **Internal Dispute**：让疗养院病房中的一只丧尸攻击另一只丧尸
- **Cat Got Your Tongue?**：Leon 在 ARK 用斧头反击切掉 Licker β2 的舌头
- **Grace and Goliath**：Grace 击杀 Chunk
- **Deadly Duet**：击杀疗养院里的两名歌唱者
- **Bang For Your Buck**：Grace 使用 Requiem 一枪击杀至少 3 名敌人
- **Master Craftsman**：Leon 制作全部可制作物品
- **Road Rage**：摩托车段打断 Victor 的攻击
- **Fatal Dose**：用 Hemolytic Injector 击杀丧尸

如果某个奖杯的挑战条件已经完成但没有跳杯，可以先重启游戏，再进入 Challenges 菜单确认一次。

### Bloodlust 的快速补法

如果还没有完成累计 5000 血液样本：

1. Grace 拿到 Blood Collector。
2. 收集 Transfusion Bag。
3. 先通过制作把 Blood Collector 中的血液消耗掉。
4. 手动存档。
5. 使用 Transfusion Bag 获得血液。
6. 读档并重复。

累计类挑战允许通过读档重复累计，因此不用真的在多个完整周目慢慢刷。

# 阶段 2：休闲难度“三合一”周目

这是你现在最重要的一个周目。

目标一次完成：

- **Speed Demon**：4 小时内，以 **Release Elpis** 结局通关
- **Never Touch the Stuff**：全程不使用 Herb 或 Med Injector 治疗
- **Minimalist**：Grace 全程不使用 Blood Collector

推荐难度：**Casual**。

## 开始前

如果 CP 足够，先购买：

- **Koketsu / Grace 的不可损坏刀**：5,000 CP

这把刀非常适合这一周目，因为 Minimalist 会限制 Grace 使用 Blood Collector，无法依赖它生产弹药。

然后继续存 CP，**不要购买模型、概念图等收藏内容**。

## 三条铁律

### 1. 不要使用任何治疗品

可以：

- 拾取 Herb
- 丢弃 Herb
- 存进箱子
- 拿去制作
- 出售
- 购买/修理 Leon 的防弹衣

不能：

- 吃 Herb
- 使用 Med Injector 治疗

Casual 难度低血量时会自动回复到黄色生命状态，这个自动回血不会破坏挑战。

随时查看：

`Challenges > Never Touch the Stuff`

计数必须始终保持 **0**。

### 2. Grace 不要使用 Blood Collector

最简单的保险做法：

> **Blood Lab 里直接不要捡 Blood Collector。**

随时查看：

`Challenges > Minimalist`

计数同样必须保持 **0**。

### 3. 最终必须选择 Release Elpis

Speed Demon 要求的是：

> **4 小时内 + Release Elpis 结局**

如果最后选另一个选项，即使时间低于 4 小时也不会拿到 Speed Demon。

## Speedrun 时间节点

4 小时其实相当宽松，熟悉流程后大约 3 小时即可完成。可以用下面的时间作为参考：

| 节点 | 建议游戏时间 |
|---|---:|
| Leon 到疗养院阁楼 | 00:45 |
| Grace 到疗养院地下区域 | 00:53 |
| Grace 开 Quartz 门到庭院 | 01:10 |
| Leon 屋顶狙击段 | 01:14 |
| Grace 水处理设施 | 01:20 |
| Leon 到达 Raccoon City | 01:25 |
| 摩托车段结束 | 02:05 |
| 孤儿院结束 | 02:17 |
| Leon 到达 ARK | 02:27 |
| Grace ARK 段 | 02:35 |
| 通关 | 约 03:00 |

暂停菜单会暂停 Speed Demon 的计时，所以需要查路线或谜题时可以直接暂停。

完成 4 小时速通后，还会解锁 **Infinite Ribbon**，对疯狂难度存档非常有帮助。

---

# 阶段 3：疯狂难度通关

目标：

- **Remarkable Agent**：Insanity 难度通关
- 顺带补齐所有低难度通关奖杯

推荐把疯狂难度放在休闲三合一之后，因为前一个周目可以提供大量 CP。

## 开始前优先购买

推荐优先：

- **Infinite Ammo**
- **Infinite RPG**
- 有多余 CP 再考虑 Grace 使用的其他奖励武器，例如 Freya's Needle

Infinite Ammo + Infinite RPG 合计大约需要 **100,000 CP**。

这些奖励物品**不会禁用奖杯**。

### Leon

Infinite RPG 基本可以秒杀普通敌人和 Boss，大幅降低疯狂难度压力。

### Grace

使用 Infinite Ammo 配合 Requiem 等奖励武器。

## 疯狂难度的注意事项

Insanity 与普通难度不只是敌人血量变化：

- 敌人更快、血量更高
- 会有额外敌人
- 后期敌人更早出现
- 部分 Antique Coin 位置不同
- 部分保险箱密码不同
- 部分关键道具位置有变化

所以不要完全凭首通记忆闭眼跑。

如果 Speed Demon 已完成并解锁 Infinite Ribbon，疯狂难度存档压力会小很多。

最终如果你已经在上一周目拿过 Release Elpis 相关奖杯，疯狂难度为了省时间可以选择另一结局路线。

---

# 阶段 4：最后再花 CP 收尾

疯狂难度通关后会拿到大量 CP，这时再处理：

- **Model Mania**：解锁并实际查看全部 44 个模型
- **Curator**：解锁并实际查看全部 56 张概念艺术

花费：

- Models：4,400 CP
- Concept Art：5,600 CP
- 合计：**10,000 CP**

注意不是购买就算完成，**还必须实际 View / 查看一遍**。

完成剩余奖杯后自动获得白金 **Requiem**。

---

# 推荐的 CP 消费顺序

对于已经首通的玩家，我建议：

1. Koketsu（5,000 CP）——用于休闲三合一
2. 保留剩余 CP
3. 完成 Speed Demon / 无治疗 / Minimalist
4. Infinite Ammo
5. Infinite RPG
6. 必要的 Grace 奖励武器
7. 完成 Insanity
8. 最后才买 Models + Concept Art

核心原则只有一句：

> **白金前期的 CP 是战斗资源，不是收藏货币。**

# 一周目重要存档点：把 12 个手动档当成“章节选择”

如果你正在跑**一周目**，并且希望通关后不必为了漏掉的收集品、杂项杯再完整重打一遍，那么最重要的事情不是频繁覆盖同一个档，而是把 **12 个手动档位固定成 12 个回档锚点**。

游戏没有传统 Chapter Select，也没有通关后的自由探索；离开很多区域后就无法返回。因此下面这些档建议**长期保留到白金完成前，不要覆盖**。

> 核心原则：看到下面的“不可逆动作”时，先手动存一个新档，再继续剧情。

## 推荐 12 档

| 槽位 | 建议存档位置 | 一定要在什么动作之前存 | 主要用途 |
|---|---|---|---|
| 01 | **Rhodes Hill Care Center：Grace 前期** | Room 201 **拔保险丝之前** | 回收疗养院最前段文件 / 前期遗漏；拔保险丝后会被强制推进到中央区域 |
| 02 | **Care Center：East Wing / Isolation Ward** | 为救 Emily **跳入地下室之前** | 很重要；Isolation Ward 之后不能再回，尤其适合补该区域文件、资源和 Grace 相关内容 |
| 03 | **Care Center Basement** | 把 **3 个 Connector Plug 全部插入面板之前** | 地下室完整回档点；用于补地下区域收集和相关挑战 |
| 04 | **Care Center：回到主楼后的最终探索阶段** | 中央大厅 **插入 3 个 Quartz 并离开主楼之前** | 疗养院主楼最后一次大范围自由探索；适合补 Files、Raccoon、保险箱、杂项杯 |
| 05 | **Courtyard / VIP Lounge** | 解完酒瓶谜题、**进入地下 Science Center 之前** | 进入地下设施后无法返回庭院，适合补庭院区域收集 |
| 06 | **Water Treatment Plant** | 恢复第 3 个供电终端 / 打开最终 Hatch 之前 | 水处理设施结束后会直接推进下一大区域 |
| 07 | **East Raccoon City** | 集齐 3 个 Detonator Parts 后，**启动炸弹之前** | 非常重要；爆破后东浣熊市永久关闭 |
| 08 | **Raccoon City Center** | **进入 R.P.D. 大门之前** | 市中心最后回档点；市中心的 Mr. Raccoon 等内容要在进警局前处理 |
| 09 | **Orphanage / Emily 回忆段** | ARK 实验区末端 **启动遥控器 / Slideshow 之前** | 回忆段不可重返；尤其用于补孤儿院、地下礼拜堂、实验室文件 |
| 10 | **R.P.D. 后段** | 从大厅北侧 **翻下瓦砾离开警局之前** | 用于补警局内容；离开后无法返回。出去后还要记得搜地下车库、Kendo 枪店和旁边小巷 |
| 11 | **Blackthorn Station / 下水道段** | **绳降深入 / 击毁 Specimen 43 之前** | 覆盖 R.P.D. 之后至后期城市段的遗漏，防止一路推进后彻底回不去 |
| 12 | **ARK 后期 / 最终决定前** | Leon 在 B.O.W. 11 Storage **进入最终电梯之前** | 最终回档。电梯后剧情会连续推进到 Grace 的结局选择，适合补结局与最后阶段挑战 |

## 额外建议：序章要不要留档？

**Wrenwood Hotel** 的不可逆点是 Grace 在 **Room 204 调查床、拿起照片**之后；如果你特别在意序章的前几份文件，可以临时留一个档。

但因为只有 12 个手动槽，而序章非常短，我更建议：

- 第一次玩时把序章文件顺手拿齐；
- 如果以后真漏了，再快速重跑序章；
- 把珍贵的长期档位留给 Care Center、Raccoon City 和 ARK 这些更长、更容易漏东西的区域。

## 哪几个档绝对不要覆盖？

如果你不想保留全部 12 个，至少保住这 **6 个核心档**：

1. **02：跳入 Care Center Basement 前**
2. **04：离开 Care Center 主楼前**
3. **07：East Raccoon City 爆破前**
4. **08：进入 R.P.D. 前**
5. **10：离开 R.P.D. 前**
6. **12：ARK 最终电梯 / 结局选择前**

这 6 个最适合通关后直接读取，用来补漏掉的收集品和一次性杂项挑战。

## 实际存档方法

不要采用：

`存档 1 → 覆盖 → 覆盖 → 覆盖`

建议直接固定：

`Slot 01 ～ Slot 12 = 上表 12 个节点`

到达下一个节点时只写入对应的新槽位。**旧档永远不覆盖**，直到你确认该区域的收集、挑战、奖杯都已经处理完。

如果当前玩的是 **Standard (Classic)**，因为手动保存需要 Ink Ribbon，更要优先把 Ribbon 用在这些关键节点，而不是随手乱存。

## 为什么这样存

《Resident Evil Requiem》没有传统章节选择，也没有通关后 Free Roam，但提供 **12 个手动存档槽**。PowerPyx 的 100% Walkthrough 同样建议在主要区域保留独立手动档，把它们当成后续快速返回各区域的办法。

主要不可逆节点还包括：

- Care Center 跳入地下、离开主楼；
- Courtyard 进入地下 Science Center；
- East Raccoon City 启动炸弹；
- City Center 进入 R.P.D.；
- R.P.D. 离开警局；
- ARK 后期最终电梯。

所以对一周目来说，**存档本身就是白金路线的一部分**。

# 进度追踪建议：GitHub Issue 非常合适

对于这种“一个游戏持续几天～几周逐步清杯”的任务，我更推荐用 **一个 GitHub Issue 做白金 Dashboard**，而不是不断修改攻略正文。

原因：

- Markdown 原生支持 `- [ ]` / `- [x]` Checklist
- 手机也能快速勾选
- 每次游玩结束可以直接追加 Comment 记日志
- 攻略正文保持干净，Issue 专门保存你的个人进度
- 白金后直接关闭 Issue，天然留下完成记录

建议结构：

```md
# 生化危机9 白金进度

## 当前状态
- [x] 首通
- [ ] 收集清理
- [ ] 休闲三合一
- [ ] Insanity
- [ ] Models / Concept Art
- [ ] 白金

## 休闲三合一
- [ ] Speed Demon
- [ ] Never Touch the Stuff
- [ ] Minimalist

## 收集
- [ ] 75 Files
- [ ] 25 Mr. Raccoons
- [ ] 5 Safes
- [ ] 3 BSAA Containers
- [ ] 9 Plant 43 Seedlings

## 高难度
- [ ] Remarkable Agent

## CP
- 当前 CP：
- [ ] Koketsu
- [ ] Infinite Ammo
- [ ] Infinite RPG
- [ ] 44 Models
- [ ] 56 Concept Arts
```

每次结束游戏，在 Issue 下写一条 Comment，例如：

```text
2026-09-13
- 文件 61/75
- 浣熊 21/25
- Bloodlust 已完成
- CP 32,400
- 下次：先补剩余文件，然后开 Casual 三合一
```

这样会比单纯在 README 里打勾更容易长期维护。
